# Project Screenshots

This directory contains screenshots for the projects displayed on the website.

## Required Images

### AfriMerkabah Adventures
- `afri-merkabah.png` - Main project screenshot (600x600px recommended)
- `afri-merkabah-hero.png` - Hero image (1200x800px recommended)
- `afri-merkabah-meta.png` - Meta/social image (1200x630px recommended)

### RADA User Interface
- `rada-ui.png` - Main project screenshot (600x600px recommended)
- `rada-ui-hero.png` - Hero image (1200x800px recommended)
- `rada-ui-meta.png` - Meta/social image (1200x630px recommended)

## Image Guidelines

- **Format**: PNG or JPG
- **Quality**: High resolution, optimized for web
- **Content**: Clear screenshots showing the main interface/dashboard
- **Alt text**: Descriptive alt text is already configured in the project files

## Adding Images

1. Add your PNG screenshots to this directory
2. Ensure filenames match exactly as listed above
3. Images will automatically be used by the website

## Fallback

If images are not available, the system will fall back to placeholder images or show broken image icons until the actual screenshots are added.
